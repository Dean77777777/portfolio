# Portfolio Website

## Overview

The project is a personal portfolio website that I created using JavaScript and Express. The purpose of the website is to show information about myself, my skills, projects, and contact information in a professional and easy to navigate format.

The website contains multiple pages that allow visitors to learn more about me, view my work, and get in touch with me.

## Features

- Home page with a personal introduction and profile picture
- About Me page with information about my education, interests, and goals
- Skills section displayed as individual cards
- Projects page showcasing my work and accomplishments
- Contact page with a form for visitors to send messages
- Links to my GitHub and LinkedIn profiles
- Easy navigation between pages using colorful buttons

## Technologies Used

- JavaScript
- Node.js
- Express.js
- CSS Styling
- bootstrapping  
Bootstrapping was used to improve the appearance and responsiveness of my portfolio. It provides pre built components such as cards, buttons, and layouts that help create a professional and mobile design.


## Pages

### Home
The home page serves as the landing page of the website and provides a brief introduction about who I am.

### About Me
This page contains information about my background, education, interests, goals, and technical skills.

### Projects
The projects page highlights projects that I have completed and demonstrates the skills I have developed.

### Contact
The contact page includes a contact form along with links to my GitHub and LinkedIn profiles so visitors can connect with me.

## What I Learned

While creating this project, I learned how to build and connect multiple pages using Express, create page navigation, style web pages, and display content dynamically using JavaScript. I also gained experience organizing a website and creating a professional online portfolio.
